Watchstander — System Architecture

A LangGraph-based multi-agent graph that evaluates concurrent shipyard work packages for hazardous spatial/temporal overlap under OSHA 1915 (Shipyard Employment), and gates anything flagged behind a genuine human-in-the-loop safety review. Deterministic detection, grounded explanation, real interrupt.
Detection: deterministic, no LLM HITL gate: real interrupt(), one pause per flagged package Grounding: public-domain OSHA/DOL case data + NAVSEA 8010

deconfliction_node

deconfliction.py — geometry/hazard-pair overlap check between work packages. Never touches an LLM: conflicts must be auditable and repeatable. This is the only place a conflict can be created or dismissed.

reasoning_node

reasoning.py — synthesizes a flagged conflict plus its grounded case citation and governing-procedure citation into a SafetyBrief. Live LLM call with a deterministic, zero-network fallback; every brief is tagged with its actual source.

hitl_prepare_node

hitl.py — splits work packages that need human review from those that don't, before any interrupt happens.

hitl_gate_single_node

hitl.py — the actual pause. Uses LangGraph's interrupt(), fanned out one per flagged package via Send(). Execution genuinely stops and waits for a human decision — not simulated, not a stub.

retrieval.py + cases_v1.json

Hand-rolled TF-IDF index over sourced, public-domain OSHA/DOL case histories. Ranks the best-matching precedent for a flagged conflict's own text, within the matching hazard category. No vector DB, no network dependency.

state.py

WorkPackageState and friends — the schema every node reads and writes. Spatial coordinates, hazard categories, risk level, HITL disposition all live here.

events.py → visualizer/

Every node broadcasts over WebSocket. The Godot 4 visualizer renders work packages, conflicts, and HITL state live on top of real USCG ACUSHNET HAER drawings — Inboard Profile and Deck Plan views.

eval/

Fixed-scenario regression harness that runs the deterministic-fallback path of deconfliction.py and retrieval.py against a checked-in baseline — catches silent drift in the parts of the system that must never depend on an LLM being online.
